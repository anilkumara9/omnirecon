# Contributing a Teardown

A teardown is a complete reverse-engineering blueprint of a real target,
generated by OmniRecon. Each one is standalone shareable content.

## How to add yours (5 steps)

1. Run autopilot on your target:
   ```
   omnirecon auto-pilot https://target.com --depth standard
   ```
2. Create `examples/teardowns/<target-name>/` with:
   - `README.md` — the story: what the target is, what you found, the most
     surprising discovery (1 surprising finding minimum)
   - `spec.json` — the 15-section blueprint (from the autopilot output)
   - `tasks.json` — the build manifest
   - `evidence.jsonl` — the evidence ledger (redacted; no secrets)
   - `screenshots/` — key page captures
   - `rebuild-score.md` — if you built a clone: what you built, the
     `recon_compare_build` score, what matched and what didn't
3. Check `evidence.jsonl` contains no secrets, tokens, or personal data.
4. Open a PR. Mention the target and your most surprising finding.
5. Once merged, your teardown appears in the gallery below and the README
   leaderboard.

## Ground rules

- Only targets you have the right to analyze (public sites, your own apps,
  open-source projects). No bypassing auth, paywalls, or CAPTCHAs.
- Every claim in `spec.json` must trace to evidence. Nothing invented.
- If the target's bot defenses blocked the browser, say so honestly in the
  README — partial teardowns are welcome.
